# Contributing to SoroProtocol Mobile

## Setup

```bash
npm install
npx expo start
```

## Running Tests

```bash
npm test
```

## Workflow

1. Branch from `main`: `git checkout -b feat/your-feature`
2. Write component tests for any new screens or components
3. Test on both iOS and Android simulators before opening a PR
4. Run `npm run lint` and ensure no TypeScript errors
